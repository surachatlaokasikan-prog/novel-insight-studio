# Patch: รองรับนิยายขนาดใหญ่ประมาณ 1,000 หน้า

แพ็กนี้เป็นส่วนเสริมสำหรับโปรเจกต์ Next.js เดิม ไม่ใช่โปรเจกต์เต็ม

## ไฟล์ที่ต้องคัดลอก

คัดลอกโครงสร้างจาก ZIP ไปวางในโฟลเดอร์โปรเจกต์เดิม โดยให้รวมโฟลเดอร์เข้าด้วยกัน:

- `app/api/analyze-chunk/route.ts`
- `lib/long-novel.ts`
- `components/long-novel-analyzer.tsx`

หากมีไฟล์ชื่อเดียวกันอยู่แล้ว ให้สำรองไฟล์เดิมก่อนแทนที่

## ติดตั้ง dependency

ใน Terminal ที่โฟลเดอร์โปรเจกต์ รัน:

```bash
npm install openai mammoth
```

ตรวจสอบว่ามี `OPENAI_API_KEY` ใน `.env.local` สำหรับทดสอบในเครื่อง และเพิ่มตัวแปรเดียวกันใน Vercel > Project > Settings > Environment Variables สำหรับเว็บออนไลน์

ตัวเลือกโมเดล:
- `OPENAI_MODEL=gpt-4o-mini` (ค่าเริ่มต้นในโค้ด)
- สามารถเปลี่ยนเป็นโมเดลอื่นที่บัญชี API ของคุณรองรับได้

## เพิ่มหน้าวิเคราะห์

ในหน้าที่ต้องการแสดงเครื่องมือวิเคราะห์ ให้เพิ่ม:

```tsx
import LongNovelAnalyzer from "@/components/long-novel-analyzer";

export default function LongNovelPage() {
  return <LongNovelAnalyzer />;
}
```

ตัวอย่างเช่นสร้างไฟล์ `app/long-novel/page.tsx` แล้วเปิด `/long-novel`

## ข้อจำกัดและข้อควรทราบ

1. ประมาณ 1,000 หน้าเป็นเป้าหมายโดยประมาณ ไม่ใช่การรับประกันจำนวนหน้าตายตัว เพราะหน้าใน DOCX ขึ้นกับฟอนต์ ระยะบรรทัด และขนาดกระดาษ โค้ดประเมินคร่าว ๆ ที่ 1,800 ตัวอักษรต่อหน้า
2. โค้ดแบ่งข้อความประมาณ 12,000 ตัวอักษรต่อชุด และซ้อนบริบท 500 ตัวอักษรเพื่อไม่ให้ขาดตอนมากเกินไป
3. การประมวลผล 1,000 หน้าอาจใช้เวลานานและมีค่าใช้จ่าย API ตามจำนวนข้อความ/โทเคน
4. ตัวอย่างนี้ส่งคำขอทีละชุดอย่างต่อเนื่องเพื่อหลีกเลี่ยงการยิง API พร้อมกันจำนวนมาก แต่ยังไม่มีระบบบันทึกสถานะลงฐานข้อมูล เมื่อปิดหน้าเว็บ งานจะหยุด
5. ระบบนี้รองรับ TXT และ DOCX ในตัวอย่าง UI นี้ ส่วน PDF ต้องเพิ่มตัวดึงข้อความ PDF แยกต่างหาก และ PDF สแกนภาพต้องใช้ OCR
6. ผลตรวจคำผิดจาก AI เป็นคำแนะนำ ควรตรวจทานก่อนนำไปแก้ต้นฉบับจริง
7. API ใช้ OpenAI SDK ฝั่งเซิร์ฟเวอร์เท่านั้น ห้ามใส่ API Key ในโค้ดฝั่ง browser หรือ commit ลง GitHub

## วิธี Deploy

หลังคัดลอกไฟล์และทดสอบแล้ว ให้ commit/push ขึ้น GitHub จากนั้น Vercel จะ deploy เวอร์ชันใหม่ตามการตั้งค่า Git integration ของโปรเจกต์
